# LINE 官方帳號

婚禮用的 LINE 官方帳號。分三階段，越早要用的越先做：

| 階段 | 時間 | 內容 | 狀態 |
|---|---|---|---|
| 1. 籌備期 | 發喜帖前 | 歡迎訊息、圖文選單、關鍵字自動回覆 —— 全在 LINE 後台設定，不用寫程式 | **本文件** |
| 2. 婚禮前 | 1–3 月 | 桌次查詢：輸入名字回覆桌號（Apps Script webhook + 桌次試算表） | 未開始 |
| 3. 婚禮當天 | 2–4 月 | 百人快問快答（LIFF 網頁 + 即時資料庫）、照片牆 | 未開始，先場勘網路 |

```
line/
├── README.md          這份：後台設定步驟與文案
└── richmenu.png       圖文選單圖片（由 tools/richmenu.ps1 產生）
```

之後階段 2、3 的 LIFF 網頁也放在這個資料夾，跟網站一起由 GitHub Pages 提供。

---

## 0. 開帳號（新人自己做）

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 建立官方帳號。名稱建議「高凱昱 ＆ 鄭采蕙 婚禮」之類一看就懂的。
2. 帳號設定 → 啟用 Messaging API（會順便在 LINE Developers 建立 channel）。階段 1 用不到，但先開好，階段 2 接程式時就不用再搬。
3. 方案用免費的「輕用量」即可。**主動推播（群發）每月有則數上限，回覆賓客傳來的訊息不算則數** —— 所以圖文選單和關鍵字回覆怎麼用都不花錢，群發留給重要通知（例如截止前提醒一次、婚禮前一天提醒一次）。

## 1. 圖文選單

後台 → 主頁 → 圖文選單 → 建立：

- **版型**：大型、6 格（3 × 2）
- **圖片**：上傳 [richmenu.png](richmenu.png)（2500 × 1686，119 KB）
- **選單列文字**：`婚禮資訊`
- **預設顯示**：開啟（加好友後選單直接展開）

每格動作都選「連結」：

| 格 | 位置 | 文字 | 連結 |
|---|---|---|---|
| A | 左上 | 出席回覆 | `https://docs.google.com/forms/d/e/1FAIpQLSf2KC6WTw8u7-nbpl1QzA3WOYhT-8m_n-2RYcjsrQ8x9he5dQ/viewform` |
| B | 中上 | 婚禮資訊 | `https://kevin890268.github.io/Wedding/#info` |
| C | 右上 | 交通導航 | `https://www.google.com/maps/search/?api=1&query=%E6%A1%83%E5%9C%92%E5%B8%82%E8%98%86%E7%AB%B9%E5%8D%80%E5%8D%97%E7%AB%B9%E8%B7%AF%E4%BA%8C%E6%AE%B5156-2%E8%99%9F%20%E5%B7%9D%E9%96%80%E5%AD%90%E6%99%82%E5%B0%9A%E9%A4%90%E5%BB%B3` |
| D | 左下 | 我們的故事 | `https://kevin890268.github.io/Wedding/` |
| E | 中下 | 祝福牆 | `https://kevin890268.github.io/Wedding/#guestbook` |
| F | 右下 | 加入行事曆 | `https://calendar.google.com/calendar/render?action=TEMPLATE&text=%E9%AB%98%E5%87%B1%E6%98%B1%20%EF%BC%86%20%E9%84%AD%E9%87%87%E8%95%99%20%E5%A9%9A%E7%A6%AE&dates=20270417T033000Z/20270417T063000Z&ctz=Asia/Taipei&location=%E5%B7%9D%E9%96%80%E5%AD%90%E6%99%82%E5%B0%9A%E9%A4%90%E5%BB%B3%20%E6%A1%83%E5%9C%92%E5%B8%82%E8%98%86%E7%AB%B9%E5%8D%80%E5%8D%97%E7%AB%B9%E8%B7%AF%E4%BA%8C%E6%AE%B5156-2%E8%99%9F&details=%E5%8D%88%E5%AE%B4%2012%3A00%20%E5%85%A5%E5%B8%AD%EF%BD%9Chttps%3A%2F%2Fkevin890268.github.io%2FWedding%2F` |

注意：

- **B、E 的 `#info`、`#guestbook` 要等 `js/site.js` 的「帶錨點跳過封面」推上 GitHub 之後才有效。** 沒推之前賓客點了會停在封面。
- **A 直接連 Google 表單**，不經過網站。網站的 `rsvp.url` 填不填都不影響圖文選單。
- **E 祝福牆**在 `guestbook.endpoint` 部署前會顯示「準備中」。後端還沒上線前可以先把這格改連 D。
- **F 的時間是 11:30–14:30**（`data.js` 的 `ceremony` / `endTime`，兩個都還是 TODO）。時間確定後重新產生連結：把 `dates=` 換成 `YYYYMMDDTHHMMSSZ/…`（UTC，台灣時間減 8 小時）。用 Google 日曆連結而不是網站的 .ics，是因為 LINE 內建瀏覽器下載檔案常常失敗。
- 改圖片文字：編輯 `tools/richmenu.ps1` 的 `$cells`，執行
  `powershell -ExecutionPolicy Bypass -File tools\richmenu.ps1`。

## 2. 加入好友的歡迎訊息

後台 → 主頁 → 加入好友的歡迎訊息。`{好友名稱}` 用後台的「好友的顯示名稱」按鈕插入，不要手打。

```
{好友名稱} 你好！

我們是凱昱和采蕙 🤍
2027 年 4 月 17 日（六）中午，在桃園川門子時尚餐廳請大家吃飯，
很希望你能來。

👇 下方選單可以：
・填寫出席回覆（2/17 前，大約一分鐘）
・查看時間地點、開啟導航
・看看我們的故事

有任何問題直接在這裡傳訊息給我們就好。
```
